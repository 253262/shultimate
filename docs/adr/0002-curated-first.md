# ADR-0002：人工裁定优先于检索

- 状态：已采纳
- 日期：2026-10-13
- 相关：`app/curated.py`、`data/curated.jsonl`、AGENTS.md §7.8

## 背景

有些问题检索层就是找不准（措辞差异、规则没写、需要跨条判断）。
Owner 亲自回答过的裁定，质量高于"检索 + 模型组织"。

## 决策

`handle_ask` 的**第 0 层**先查疑问库；命中就绕过检索和生成，直接用 Owner 的答案。
引用只取 Owner 点名的条款，并显式标「人工核定」——不得伪装成官方正文。

## 后果

- ✅ 高频/高风险问题稳定拿到正确回答
- ✅ 不依赖模型当天的状态
- ⚠️ **它绕过检索，所以三把检索尺子测不到它** —— 必须单独有一把
  `tools/curated_precision.py`；否则它答错了也没人知道（真踩过）
- ⚠️ 同分并列必须 fail-closed（返回 None），不能靠文件顺序决胜
- ⚠️ 疑问库会"抢"问题：命中错误比未命中坏得多（未命中只是掉回检索）

## 被否决的替代方案

- **把裁定当普通语料**：会被检索排名压下去，等于没有优先
- **让模型改写裁定**：引入二次编造风险，违背"人工核定"的信任基础
