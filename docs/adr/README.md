# 架构决策记录（ADR）

每份 ADR 记录一个**当时做出的选择**，以及被否决的替代方案。它们是历史证据，
不是当前说明书——与代码冲突时以代码和实测为准。

> **关于"相关"行的说明**：部分 ADR 的"相关"行指向 `AGENTS.md`（内部交接书）
> 与 `tools/` 下的脚本。这些文件属内部资产，**未随本仓库发布**，
> 因此那些路径在本仓库中不存在。ADR 正文本身不依赖它们，可以直接读。

> 这里只记**改了会疼**的决定：为什么不用某个东西、为什么把某个东西放在前面。
> 每条 ADR 只回答三件事：当时面对什么、选了什么、代价是什么。
> 代码会变，理由不会；下一任维护者先读这里，再去读代码。
