# ADR-0003：只做浏览器启动器，不做 Electron 客户端

- 状态：已采纳
- 日期：2026-10-13
- 相关：`tools/build_desktop_launcher.py`、AGENTS.md §2.0.10

## 背景

两种交付形态：

1. **Electron 客户端**：界面打包进客户端，只有 `/api/*` 走网络；
   每次改界面都要重新打包、发版、用户重装。
2. **浏览器启动器**：一个 7.4MB 的 exe，双击打开一个 Chrome `--app` 窗口；
   界面每次从服务器加载。

owner 的诉求是「只点一个图标，永远用最新版」。Electron 的 GUI 在开发机上
**实测点不开、根因未定位**，无法验证"用户看到的是什么"。

## 决策

只交付**浏览器启动器**。唯一交付目录 `release/Shultimate.exe`。
Electron 产物归档，不再维护。

## 后果

- ✅ 改 `static/` / `app/` **不需要发版**，用户下次打开就是新的
- ✅ 只有启动器外壳需要发版（域名、开窗、自安装、更新器）
- ✅ 界面能在真实 Chrome 里验证（截图/CDP），不再"开发机点不开"
- ⚠️ 依赖用户机器上有 Chrome/Edge；没有就退回系统默认浏览器
- ⚠️ 离线不可用（界面不在本地）
- ⚠️ 启动器更新是"后台替换、下次启动生效"，不是即时生效

## 被否决的替代方案

- **Electron**：发版成本高、GUI 无法验证
- **PWA**：安装体验和桌面图标不如 exe 直接，且 Windows 上依赖浏览器
